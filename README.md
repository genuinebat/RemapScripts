# Editing and testing scripts

Always ensure that scripts are opened and edited with notepad to avoid any complications

Testing procedure
1. Double click the .ahk script file to run it

2. Check if the script is running by
selecting the "^" arrow located in the bottom right of the windows task bar
check if an AHK icon appears in the menu that popped up,
if there is means that the script is running

4. Proceed to test functionality

5. Once done, right click the AHK icon in the pop up menu and select "Exit" to close the instance of the script


# Creating .exe files from .ahk files

1. Double click the Ahk2Exe.exe file to open the GUI

2. Select the .ahk file you would like to convert

3. Select the destination for the .exe file to be created in (by default it is the same folder as the Ahk2Exe.exe file)

4. Select "Convert"
